# Studio orientation

Version 0.8.24 adds a Defold GUI button at the physical top center of every page.
It switches between portrait (480×800) and landscape (1280×720) without navigating
away. The web bridge persists the selection in localStorage and attempts fullscreen
and Screen Orientation locking where the browser supports it. When locking is
unavailable, the selected canvas layout still works; physically rotating the device
provides more space. No browser DOM controls are added.

`shared/display/viewport.lua` owns the selected GUI reference. The manual display
profiles in `shared/display/orientation.display_profiles` set GUI reference sizes;
`shared/display/layouts/{portrait,landscape}/` builds each presentation. Input,
routing, character motion and scene settings remain in their shared controllers.
Changing presentation preserves equipment, active animation timers, fish/water
visibility, particle counts, wind and water sliders. Pointer holds are released on
switch to prevent stuck flight or sliders. FPS sampling restarts for the new view.

The world camera remains 720 units high and centered at x=640. Sky/water geometry,
72/26 default particle counts, zero-count controls, 163-point water mesh and motion
units are unchanged. Characters use uniform scale; landscape gallery/equipment/object
presentations in `shared/display/artwork/landscape/` are true Rive vector assets,
generated by `scripts/defold_rive_layouts.py` from the shared SVG/vector painters.
No sprites or rasterization are introduced.

`scripts/web_preview/orientation.js` frames the existing Defold canvas. DPR remains
unchanged and uncapped. The Rive WebGL resize repair stays active. The native display
reference defaults to portrait and permits device orientation changes; this release
builds only Web. Desktop native builds can resize their window through the button.

Browser QA covers both layouts, switching on active character/scenery routes,
input after switching, state preservation, persisted selection and resize. Cloud
SwiftShader FPS does not measure the user's phone. Web delivery uses the existing
private Sites URL, and source checkpoints stay on defold/development without a PR.
